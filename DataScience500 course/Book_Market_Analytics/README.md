# Book Market Analytics – Books to Scrape
**Data Science 500 · 402308101 · Due 23 October**

## How to run (PyCharm)
1. Open this folder as a project
2. Terminal: `pip install -r requirements.txt`
3. Right-click **`main.py`** → Run

That one file is the full assignment pipeline:
- PART A – scrape (or load existing books_raw.csv)
- PART B – clean → books_clean.csv
- PART C – charts → charts/
- PART D – linear regression on price

Optional step files (`01_scrape.py` … `04_model.py`) do the same work in smaller pieces if you prefer.

## What to submit on Moodle
1. **Code** – this project (especially `main.py`) — PyCharm only, no notebook
2. **Dataset** – `books_clean.csv`
3. **Report** – PDF (export from `Book_Market_Analytics_Report.docx`: cover, declaration, Harvard, Times New Roman 12, 1.5 spacing)
